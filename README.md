# Teste Técnico - Desenvolvedor Jr

## Objetivo
Corrigir bugs e implementar melhorias em um sistema de gerenciamento de tarefas existente.

## Problema
Você recebeu um projeto de gerenciamento de tarefas que possui alguns problemas. Sua missão é:
1. **Instalar e executar** o projeto localmente
2. **Identificar e corrigir** os bugs existentes
3. **Implementar melhorias** se houver tempo

## Funcionalidades Esperadas
- Adicionar novas tarefas
- Listar todas as tarefas
- Marcar tarefas como concluídas
- Remover tarefas

## Versões Disponíveis
Escolha uma das versões para trabalhar:
- **Node.js**: `projeto-nodejs/`
- **PHP**: `projeto-php/`

## Instruções
1. Escolha uma versão (Node.js ou PHP)
2. Siga as instruções do README da versão escolhida
3. Execute o projeto e teste as funcionalidades
4. Identifique os problemas encontrados
5. Corrija os bugs e documente as soluções

## Critérios de Avaliação

### Técnicos
- Capacidade de identificar e corrigir bugs
- Processo de debugging utilizado
- Qualidade das correções implementadas
- Documentação das soluções

## Tempo
- Correção de bugs: 1-2 dias
- Apresentação: 35 minutos

## Entrega
- **Pull Request** com as correções implementadas
- Arquivo `SOLUCOES.md` documentando o processo
- Projeto funcionando corretamente
- Apresentação do processo de debugging

## Dicas
- Teste todas as funcionalidades primeiro
- Use ferramentas de debug (console, logs)
- Documente cada problema encontrado
- Explique seu raciocínio durante a correção
- Não tenha medo de fazer perguntas
