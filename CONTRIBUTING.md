# Como Contribuir

## Processo de Entrega

### 1. Fork e Clone
```bash
# Fork este repositório no GitHub
# Clone seu fork
git clone https://github.com/essentiadigitalaccounts/desafio-desenvolvedor-jr.git
cd desafio-desenvolvedor-jr
```

### 2. Criar Branch
```bash
git checkout -b fix/correcao-bugs
```

### 3. Trabalhar na Solução
- Escolha uma versão (Node.js ou PHP)
- Execute o projeto e identifique os bugs
- Corrija os problemas encontrados
- Teste todas as funcionalidades

### 4. Documentar as Correções
Crie um arquivo `SOLUCOES.md` documentando:
- Bugs encontrados
- Como identificou cada problema
- Soluções implementadas
- Processo de teste

### 5. Commit e Push
```bash
git add .
git commit -m "fix: corrige bugs do sistema de tarefas"
git push origin fix/correcao-bugs
```

### 6. Criar Pull Request
- Abra um PR para a branch `main`
- Use o template fornecido
- Descreva as correções implementadas

## Critérios de Avaliação

### Pull Request (20%)
- Qualidade da descrição
- Commits organizados
- Documentação clara

### Código (30%)
- Bugs corrigidos corretamente
- Código limpo e funcional
- Testes das funcionalidades

### Processo (50%)
- Metodologia de debugging
- Documentação do processo
- Explicação durante apresentação
